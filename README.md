# 🩺 Diabetes Prediction using FFNN

## 📌 Overview
This project is a deep learning-based Diabetes Prediction System developed using TensorFlow and Keras. The model predicts whether a person is diabetic or non-diabetic based on medical parameters using a Feed Forward Neural Network (FFNN).

---

## 🚀 Features
- Diabetes prediction using deep learning
- Built using Feed Forward Neural Network (FFNN)
- Real-time prediction system
- User-friendly web interface
- Data preprocessing and model optimization

---

## 🛠️ Technologies Used
- Python
- TensorFlow
- Keras
- Pandas
- NumPy
- Matplotlib
- Streamlit

---

## 📊 Dataset Information
- Pima Indians Diabetes Dataset
- Total Samples: 768
- Features: 8 medical input parameters
- Binary Classification:
  - 0 → Non-Diabetic
  - 1 → Diabetic

---

## ⚙️ Model Performance
- Achieved 85.55% prediction accuracy
- Applied preprocessing and feature scaling techniques
- Compared FFNN performance with traditional machine learning models

---

## 📊 Project Workflow
1. User enters medical parameters
2. Data preprocessing and normalization
3. FFNN model prediction
4. Display prediction result
